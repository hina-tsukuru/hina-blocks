
## D. 詰まった系 → 学び（閉じ込め事故）

型: 学び系（今回いちばん強い） / 画像: `face-trouble.png`

```
作ってて一番ゾッとしたやつ。

ブロック中に対象の選択が空になると、
「対象が無いから」ボタンが押せなくなる設計になってました。

つまり**自分で掛けたブロックを、自分で解除できなくなる**。

スマホ依存を直すアプリが、ユーザーを閉じ込める。
笑えないので、「解除だけは絶対にできる」をテストで固定しました
```

## E. 学び系（「何のため?」の話）

型: 学び系 / 画像: `scene-cafe-work.png` または画像なし

```
AIくんに「録画してください」と言われて、
なんとなく「それ何のためにやるんですか?」って聞いたんです。

そしたら調べ直して「やらなくていいです」と。

計画表に書いてあっただけで、使う予定がどこにも無かった。
危うく2時間ぶん撮るところでした。

技術は分からなくても「それ何のため?」は聞ける。
今のところこれが一番役に立ってます
```

## 投稿順の推奨

1. **B**（悲報）→ 2. **C**（解決）を同日〜翌日で。詰まり→解決のセットは続けて出すと読まれやすい
2. **D** を単独で。今回いちばん刺さる可能性が高い
3. **A** は記事公開に合わせる（要URL）
4. **E** はいつでも。AI駆動開発の文脈で拾われやすい

## 使わなかった素材

- **勤務先の開発者チームが同じApple IDに同居していた件**: `character.md` の「実在の人物・企業への言及はしない」に抵触。社名を伏せても勤務先の情報になるため不採用
- **デフォルト引数と actor 隔離の話**: 技術的には良いが、非エンジニア読者に翻訳しきれず断念
